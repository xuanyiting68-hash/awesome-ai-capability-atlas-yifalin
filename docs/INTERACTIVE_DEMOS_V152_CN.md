# Atlas V1.5.2｜普通用户可直接操作的 AI 体验中心

## 打开方式

正式部署后访问 [AI 体验中心](../demos.html)，或从 [Atlas 首页](../index.html) 和 [能力组合研究工作台](../recipes.html) 点击“立即体验”。

三项均可用鼠标或手机触屏直接操作，不需要 GitHub 账号、Python、命令行、注册、API Key、云电脑或付费模型。可将场景直达链接分享给其他用户：`demos.html?scenario=leads`、`?scenario=education`、`?scenario=finance`。

**定位必须严格区分**：

- **浏览器端交互**：实际运行静态网页内的*第一方 JavaScript 确定性算法*，处理仓库发布的纯合成输入。不是调用 ChatGPT/真实 LLM，也没有运行任何候选第三方 Agent、MCP、Qlib、CRM、RAGFlow。
- **服务器上的基准证据**：发布前运行原有第一方 Python 代码和固定验收合同，生成 `data/recipe_demo_results.json`。浏览器会读入这一基准，并核验固定成本下的金融毛/净合计，以避免静态假数据冒充交互计算。
- **隔离与隐私**：页面只 fetch 自己 GitHub Pages 站点的公开固定 fixtures 和 Python 基准 JSON。新输入的选中状态、答案片段和成本参数**不发送给服务器，也不会存入 localStorage**；无账号、第三方遥测、交易接口、客户真实资料。
- **非商业集成**：第三方集成数仍为 0；可操作性、数据处理模拟成功与生产安全许可审查是不同的等级。

## 实际交互

1. **合规获客**：展示已提交的 8 条匿名合成线索。每条“允许联系”和“退订”均可切换，立即复算。如果客户 ID 重复、同意超期、用途不同或已退订，不能因单独勾选同意而被放行。初始 3 条符合条件、5 条阻断，所有外部联系次数保持 0。
2. **AI 教育**：显示 3 段原创合成英文讲义、4 道预设练习问题。选择问题后，返回原文中确定存在的片段和 source ID，或对于无依据承诺显示“拒绝回答”。用户可以选择一个来源，输入候选答案（最多 200 字符），本地验证是否为对应原文中连续出现的片段。**只验证字符串归属，不判断语义真伪、概念等价或真实教学质量。**
3. **金融模拟研究**：按已有固定 20 个完全虚构价格、冻结训练边界 10 与原始简单规则，展示 9 个样本外假设方向判断。初始毛值 +10.21 bps，三项成本合计 16.00 bps/假设交易，成本后总值 −133.79 bps；滑动点差、佣金、滑点可以实时重新计算每笔与合计成本。调整后的结果**只是用户自选成本情景，不能继承原 Python 固定合同“已验证”的标签**。没有实际数据、账户、下单或投资收益承诺。

## 真实验收与发布门禁

- `scripts/build_site.py` 必须先通过原有 `verify_recipe_demos` 与全部目录研究合同，发布产物包含 `demos.html` 和真实合成 fixtures。
- `tests/deployed-smoke.cjs` 使用真实 Chrome 在电脑、平板、手机三种分辨率启动页面，检查三条场景真的可点击并反应：撤销同意由 3/5 变 2/6；文档无来源题拒绝回答；伪造引用不通过、正确片段通过；点差从 6 改 0 时，9 次样本外成本合计减少 54 bps，净值由 −133.79 变 −79.79；恢复参数回到 −133.79；分享深链与刷新保持正确场景。
- `scripts/test_build_site.py` 和 `deployment.json` 明确 3 个浏览器互动场景、第三方集成为 0。
- PR 对应精确提交的原 CI 检查必须全绿，合并后 GitHub Pages 需要重新部署及真正的 `verify-online / smoke` 才宣称正式可用。

未来需要真实用户的体验数据，应另行征得同意，并基于专门设计的隐私政策及分析系统；本次不启用隐式数据采集。
