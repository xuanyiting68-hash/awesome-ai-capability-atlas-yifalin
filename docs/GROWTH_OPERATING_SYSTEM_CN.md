# YIFALIN · AI Growth Operating System | 内容与商业增长闭环

> 版本：2026-10-26。架构建议与开源项目研究索引，不代表任何功能已经部署或已获得第三方平台 API 许可。

## 1. 目标

形成一条从**研究驱动原创内容 → 视频 / 图文资产 → 合规跨渠道发布 → 主动咨询 / 授权留资 → 线索评分 → CRM 管理 → 客户激活与长期维护 → 数据反馈**的可观测链路。

特别适用于 YIFALIN 金融 AI 教育、智能研究产品、AI 交互教育、自媒体业务。避免混用金融研究内容与直接交易推荐；财经内容须有原创研究证据、本人出镜或原创表达以及适当风险声明。

## 2. 六个模块与可复用仓库

| 模块 | 入口 | 候选仓库 | 交付标准 |
|---|---|---|---|
| 内容研究与选题 | 公开论文、公司公告、用户问题 | `unclecode/crawl4ai`、`firecrawl/firecrawl`、`n8n-io/n8n` | 原始来源、核实日期、原创观点、引用链 |
| 视频与多语制作 | 审核通过的原创脚本 | `remotion-dev/remotion`、`SYSTRAN/faster-whisper`、`FFmpeg/FFmpeg`、`comfyanonymous/ComfyUI` | 竖版 9:16 / 横版 16:9、准确字幕、人工 QA、授权素材 |
| 多渠道分发 | 审核通过的成品 | `gitroomhq/postiz-app`、`inovector/mixpost` | 平台差异化标题、排期、授权发布、失败回执 |
| 用户咨询与获客 | 自愿提交的表单、预约、公开的 B2B 机构信息 | `formbricks/formbricks`、`baptisteArno/typebot.io`、`calcom/cal.com` | 客户明确知情同意、来源与时间记录、可撤回 |
| CRM 与服务 | 线索评分、合规沟通 | `TwentyHQ/twenty`、`chatwoot/chatwoot`、`mautic/mautic` | 销售阶段、客服交接、服务满意度、退订与删除 |
| 量化增长分析 | 第一方匿名或授权事件 | `posthog/posthog`、`dubinc/dub`、`GrowthBook/growthbook` | 渠道归因、转化率、有效线索率、留存/付费/退订 |

## 3. 全智能获客的运行状态机（受控）

1. **Discover:** 发现公开行业需求/机构，不自动收集敏感私人信息，遵守来源服务条款。
2. **Qualify:** 用可解释字段（领域、业务需求、企业规模、地区、自愿提交的信息）评分；保留人工更正入口。
3. **Capture:** 使用落地页、自愿登记、活动问卷、公开的企业联系渠道，记录许可范围。
4. **Engage:** 已明确授权的联系人进入欢迎、教育内容或约谈旅程；**对外首次触达及大批量发送默认人工审批**。
5. **Assist:** FAQ → 预约演示 → 人工咨询；避免机器人冒充真人。
6. **Retain:** 产品使用引导、续费提醒、反馈征集，依据用户偏好、合法性与通知设置触发。
7. **Measure:** 成功转化率 / 有效咨询率 / CAC / 人工处理时长 / 退订投诉 / 留存变化。

## 4. 可量化核心指标

| 阶段 | 主要指标 | 解释 |
|---|---|---|
| 内容 | 有效内容产出、人审通过率、每条制作工时 | 不用单纯发帖数量作为成功指标 |
| 触达 | 官网有效访问、搜索量、点击率、平均观看完成率 | 防止虚假流量或重复计数 |
| 获客 | 授权线索数、有效线索率、合规来源覆盖率 | 不追逐未授权个人联系方式 |
| 销售 | 首次响应时效、预约完成率、试用激活率、付费转化率 | 用 CRM 状态而不是营销直觉计量 |
| 留存 | 7/30 天激活/留存、客服满意度、流失率、退订率 | 将服务体验和隐私偏好纳入 |
| 可靠性 | 任务完成率、错误回滚率、发布失败率、人工升级率 | 每个自动化任务需有可追踪 ID |

## 5. 可落地的示例：一条金融数学短视频

Research Agent 采集公开资料 → Research QA 核验与复算 → Script Agent 生成原创脚本 → 人工检查合规与表达 → Remotion/FFmpeg 渲染字幕视频 → Postiz 适配**平台实际支持的 API**并发送待审排期 → 自愿咨询表单 → Twenty CRM → Chatwoot 跟进 → PostHog 统计效果 → 决定下一期选题。

**平台特殊性：** 抖音、小红书、B 站、微信视频号等的发布接口、可用性、账号要求与平台条款必须逐一核实；海外排期工具不应宣称天然支持国内账号。

## 6. 审批和数据门禁

- 无对外自动群发默认许可；发送频控、取消订阅/退订与投诉处理必须先具备。
- 区分公开 B2B 机构资料与用户个人信息；不采集、购买或拼接未经授权的个人联系方式。
- 内容使用自有/授权图片、声音和视频；不得未经许可克隆他人声音或肖像。
- 各平台遵循官方 API 与账号规则，禁止绕过限制、自动批量骚扰。
- AI 自动发送、自动录入、修改 CRM 记录、退款/收费都需可追踪日志、权限隔离与回滚。
- 财经研究避免直接买卖点位、收益暗示。公开财经短视频应添加原创解释和合规声明。
- 商业 Fork 前逐项目核实代码许可证、素材/模型权重许可证、商标与数据使用条款。

## 7. 分阶段评估而非一次性安装

**P0 / 原型：** 选 1 个视频引擎 + 1 个排期工具 + 1 个表单 + 1 个 CRM + 1 个分析平台。用演示数据验证“文章到预约”的全过程。

**P1 / 小范围试点：** 自有素材及已授权真实用户；测量每周人工节省工时、发布失败率、合规处理时效和有效线索。

**P2 / 商用前审查：** 许可证、数据处理协议、平台发布授权、账号权限、隐私披露、营销许可及地方适用法律。

## 8. 项目不包含的功能

不提供未经许可获取个人资料、群发骚扰、批量绕过平台安全限制、伪造真人身份、虚构投资业绩或无风险交易收益的能力。
