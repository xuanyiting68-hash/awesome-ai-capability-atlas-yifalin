# Agent 权限与安全审查

**状态：** 第一方工作流模板；未在真实业务环境执行或完成生产安全验证。

## 目标
在实施前检查 Agent、Skills、MCP 的真实权限

## 授权输入
候选技能清单、依赖、触发器、敏感资源

## 步骤
1. 检查作者与许可证
2. 列出读写权限
3. 运行隔离恶意输入测试
4. 验证人工审批
5. 制定中止与回滚步骤

## 交付物
权限矩阵、负面测试、上线门槛

## 验收指标
越权率/无授权调用次数

## 人工审批 / 风险门槛
不得默认授予密钥、终端、支付或生产写入权限

## 执行约束
在明确授权的数据、工具与环境中工作；交付中标注来源、不确定性、失败条件。外部发送、支付、关键系统写操作须经人类授权，不因模板存在而获得默认权限。
